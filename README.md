# Adari

**Built for Herdr.** Keep Herdr. Step out of the terminal.

Adari is a Mac app for [Herdr](https://herdr.dev): first-class Chat for Claude Code and Codex, and the real terminal for every coding agent you run in Herdr, across all your Macs.

## Download

Get the latest `.dmg` from [Releases](https://github.com/rkvhtd/adari-app/releases/latest). The app is signed and notarized, and it updates itself from this repository's releases.

## What you need

- A Mac with Apple silicon on macOS 13 Ventura or later.
- Herdr on each Mac that runs your agents. Check it in Terminal with `herdr --version`.
- To reach another Mac, Remote Login turned on there.

## Agents

- Chat is first class for Claude Code and Codex: read the conversation with its tools and thinking, answer questions and approvals, and pick the model and effort while the agent runs.
- Chat is early for 15 more agents, marked Early in the app. It reads their sessions and can miss things.
- Every agent Herdr runs works in the Terminal view, exactly as it does in Herdr.
